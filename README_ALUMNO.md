# 🛒 Tienda Virtual con IA - Guía Rápida

## ✏️ ¿Qué archivos podés editar?
- **`data/candidatos.json`**: Agregá o cambiá los 3 productos a investigar.
- **`data/reglas.json`**: Modificá tu presupuesto y la ganancia mínima deseada.
- **`agente/instrucciones.md`**: Ajustá la personalidad e instrucciones del agente IA.
- **`data/productos.json`**: Completá el costo de envío o impuestos de cada producto.

## 🚀 ¿Cómo correrlo?
- **En Mac**: Hacé doble clic en **Abrir Tienda.command**.
- **En Windows o Terminal**: Corré `npm run demo`.
- Luego abrí **`ranking.html`** en tu navegador para ver los resultados.
